# Code of Conduct

This repository follows the SkillBag project expectation of respectful,
constructive collaboration.

Contributors should:

- assume good faith
- keep discussion focused on the work
- make room for maintainers and users with different backgrounds
- avoid harassment, personal attacks, or discriminatory language
- report security issues through the security process rather than public
  threads

Maintainers may moderate or close discussions that are hostile, off-topic, or
unsafe for contributors.
