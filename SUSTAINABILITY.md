# Sustainability

SkillBag Workflows is maintained as part of the SkillBag ecosystem.

The project aims to keep common AI-assisted work routines reusable without
locking them to one provider, organization, or project management system.

## Funding Principles

- Funding may support maintenance, documentation, tests, examples, and
  compatibility work.
- Funding does not grant control over the standard or repository scope.
- Sponsored work should remain reusable unless it is clearly marked as
  project-specific and kept out of distributed skills.
- Security and compatibility fixes take priority over broad feature expansion.

## Maintenance Priorities

Maintenance focuses on:

- keeping workflow skills small and composable
- preserving clear write boundaries
- keeping catalog metadata synchronized
- updating skills when the SkillBag standard changes
- retiring or moving skills that belong in another companion repository

## Scope Discipline

Workflow skills should stay practical and routine-oriented. A proposed skill
that mainly performs format conversion, media processing, resource indexing,
or SkillBag maintenance likely belongs in another repository.
